คู่มือการใช้งาน RAZOR IDE

RAZOR IDE ออกแบบมาให้ใช้งานง่าย ไม่ซับซ้อน แม้ไม่มีพื้นฐานเขียนโปรแกรมมาก่อน หน้านี้รวบรวมวิธีเริ่มต้นใช้งาน ภาพรวมหน้าจอ และปุ่มลัดที่ควรรู้

เริ่มต้นใช้งาน

  1. ดาวน์โหลดตัวติดตั้งจากหน้าดาวน์โหลดแล้วรันไฟล์ .exe
  2. เปิดโปรแกรม RAZOR IDE — ระบบจะสร้างโปรเจกต์ใหม่ให้อัตโนมัติ พร้อมบล็อก Setup และ Loop
  3. กด Boards บนแถบเครื่องมือ เพื่อเลือกบอร์ดที่ใช้งาน (ดูรายชื่อที่รองรับด้านล่าง)
  4. เสียบบอร์ดกับคอมพิวเตอร์ แล้วกด Setup เพื่อเลือกพอร์ต COM และ baud rate — โปรแกรมจะจำค่าที่ใช้ล่าสุดไว้ให้ในครั้งถัดไป
  5. ลากบล็อกจากเมนูซ้ายมาต่อในพื้นที่ทำงาน แล้วกด Compile เพื่อตรวจสอบ หรือ Upload เพื่ออัปโหลดขึ้นบอร์ด
💡 RAZOR IDE ทำงานออฟไลน์ได้ 100% — ต่อเน็ตเฉพาะตอนตรวจสอบอัปเดตโปรแกรมหรือบอร์ดใหม่เท่านั้น
🎮 ยังไม่มีบอร์ดจริงในมือ? ลองเขียนโค้ดกับหุ่นยนต์จำลองผ่านเบราว์เซอร์ได้ที่ RazorSIM ใช้บล็อกชุดเดียวกับ RAZOR IDE และบันทึกไฟล์ .srazor มาเปิดต่อในโปรแกรมนี้ได้ทันที

ภาพรวมหน้าจอ

แถบเครื่องมือด้านบนมีปุ่มหลักดังนี้:

ปุ่มหน้าที่
Newสร้างโปรเจกต์ใหม่
Boardsเลือก/สลับบอร์ดที่ใช้งาน
Pluginsจัดการปลั๊กอินเสริม เช่น เซนเซอร์พิเศษ
Generateดูโค้ด C++ ที่แปลงมาจากบล็อกปัจจุบัน
Block / Codeสลับระหว่างโหมดลากบล็อก และโหมดเขียนโค้ด
Save / Openบันทึก / เปิดโปรเจกต์
Compileคอมไพล์โปรแกรมตรวจสอบข้อผิดพลาด
Uploadคอมไพล์แล้วอัปโหลดขึ้นบอร์ดทันที
Connectเชื่อมต่อ Serial กับบอร์ดที่เลือก
Setupตั้งค่าพอร์ต COM และ baud rate

ด้านล่างของโปรแกรมมีแท็บ Serial Monitor (ดู output แบบ real-time), Compile Output (log การคอมไพล์) และ Plotter (กราฟค่าที่ส่งมาจากบอร์ด)

โหมด Block และ Code

Block Mode ใช้ลากบล็อกจากหมวดหมู่ทางซ้าย (เช่น Motor, Sensor, Logic, Loops, Variables) มาต่อกันเป็นลำดับการทำงาน เหมาะสำหรับผู้เริ่มต้น

Code Mode เป็นตัวแก้ไขโค้ด Arduino C++ แบบเต็มรูปแบบ (ใช้ Monaco Editor ตัวเดียวกับ VS Code) รองรับหลายไฟล์ในโปรเจกต์เดียว กดปุ่ม + ข้างแท็บไฟล์เพื่อเปิดไฟล์ใหม่

สลับไปมาระหว่างสองโหมดได้ตลอดเวลาโดยกดปุ่ม Block/Code บนแถบเครื่องมือ

บอร์ดที่รองรับ

บอร์ดรายละเอียด
RAZOR-S3บอร์ดหุ่นยนต์การศึกษาของ Razor Robotics (C++) — มี IMU นำทาง, จอ OLED และมอเตอร์แบบ PID ในตัว
RAZOR-S3 Pythonบอร์ดหุ่นยนต์การศึกษา (MicroPython/Python)
RAZOR-S2บอร์ดหุ่นยนต์การศึกษา ใช้ชิป ESP32
ANT-S1บอร์ดหุ่นยนต์การศึกษา
Arduino NanoATmega328P มาตรฐาน
ESP32รองรับ WiFi / Bluetooth
Raspberry Pi Picoชิป RP2040

ต้องการเพิ่มบอร์ดใหม่ที่ไม่อยู่ในรายชื่อนี้? ดูหัวข้อ สำหรับนักพัฒนา Board ด้านล่าง

ฟีเจอร์เด่นของ RAZOR-S3

นอกจากบล็อกพื้นฐานที่มีทุกบอร์ด RAZOR-S3 ยังมีบล็อกพิเศษเฉพาะตัวสำหรับงานหุ่นยนต์ขั้นสูง ดังนี้

นำทางด้วย IMU (รองรับ MPU6050, BNO055, BNO085, ICM20948, GY-91)

คาลิเบทเข็มทิศครั้งแรก ตั้งค่า Scale ให้ตรงกับเซนเซอร์ แล้วรีเซ็ตทิศก่อนเริ่มงานได้ทันที มีบล็อกอ่าน มุมปัจจุบัน และ มุมดิบ (raw) พร้อมตั้งค่า PID สำหรับหมุนเข้าทิศ (kp_fast, kp_mid, kp_slow, kd) และบล็อก MOVE ที่สั่งวิ่งตามทิศ+ความเร็วโดยคุม PID ให้เดินตรงแนวอัตโนมัติ แม้พื้นไม่เรียบหรือมอเตอร์ซ้าย-ขวาไม่เท่ากัน

จอ OLED ในตัว

แสดงข้อความ วาดรูปทรง (เส้น สี่เหลี่ยม วงกลม ทึบ/โปร่ง) และแถบความคืบหน้าบนจอ OLED ที่ติดมากับบอร์ด ปรับความสว่างหรือกลับสี (invert) ได้ ใช้โชว์สถานะหุ่นยนต์หรือทำเมนูบนตัวบอร์ดได้เลยโดยไม่ต้องต่อจอเสริม

คู่มือพัฒนาบอร์ด (Board Developer Guide)

RAZOR IDE รองรับการเพิ่มบอร์ดใหม่เองผ่านระบบ Board Plugin คุณสามารถพัฒนาบอร์ดหุ่นยนต์ของตัวเองเพื่อนำมาใช้งานร่วมกับซอฟต์แวร์ได้อย่างรวดเร็วและเป็นระบบ

📄
config.json & toolbox.xml ระบุข้อมูลพื้นฐานของบอร์ด และจัดระเบียบหมวดหมู่บล็อกลากวางส่วนตัว
🧩
blocks.js & generator.js สร้างหน้าตาบล็อกสั่งงานเฉพาะตัว และแปลงบล็อกเหล่านั้นเป็น C++ เพื่อส่งคอมไพล์
⚡
Runtime & Library Files รวมไฟล์ไลบรารีที่จำเป็นที่จะถูกฝังและรันบนบอร์ดหุ่นยนต์ของคุณแบบอัตโนมัติ
