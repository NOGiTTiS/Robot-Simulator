🔋 ชดเชยแรงดันแบตเตอรี่ (Battery Compensation)

เมื่อแบตลด มอเตอร์จะอ่อนลงและหุ่นวิ่งช้าลงเรื่อยๆ — โหมดนี้ชดเชยด้วยการปรับ PWM ให้มอเตอร์ "รู้สึก" เหมือนได้ไฟคงที่ตลอด ไม่ต้องใช้ step-down

voidsetMotorVoltage(vref)
เปิดโหมดชดเชยแรงดันแบต — ตั้งครั้งเดียวใน setup()
setup()มอเตอร์
▶
พารามิเตอร์ชนิดค่าเริ่มต้นคำอธิบาย
vreffloat7.0แรงดันอ้างอิงที่อยากให้มอเตอร์รู้สึก (V) — แบต 2S แนะนำ 7.0
💡 ทำงานยังไง: แบตเต็ม (เกิน vref) → ลด PWM ลง · แบตลด (ต่ำกว่า vref) → เพิ่ม PWM ชดเชย ทำให้ความเร็วคงที่ตลอดการแข่ง · ตั้ง vref ใกล้ค่ากลางของแบตเพื่อชดเชยได้เกือบเต็มช่วง
⚠ ปิดโหมด: ไม่เรียกบล็อกนี้ = โหมดปกติ (PWM ตรงๆ) · ถ้าเปิดไว้แล้วอยากปิดกลางคันเรียก disableMotorVoltage()

void setup() {

IMU / ไจโร (เลือกได้ 8 ชนิด)
อ่านมุม yaw และหมุนหุ่นยนต์ด้วยมุมที่แม่นยำ — รองรับ BNO055 · BNO085 · ICM-20948 · MPU6050 · GY-91 (เลือกด้วย setIMU())
voidsetIMU(type)
เลือกชนิดเซนเซอร์ IMU — วางบนสุดของ setup() ก่อน initIMU()
setup()IMUเลือกได้ 8 ชนิด
▶

บอกระบบว่าใช้เซนเซอร์ IMU รุ่นไหน — เรียกก่อน initIMU() / calibrateYawStart() เสมอ ถ้าไม่เรียกบล็อกนี้ ระบบจะใช้ BNO055 เป็นค่าเริ่มต้น

ค่า typeเซนเซอร์หมายเหตุ
IMU_BNO055BNO055ค่าเริ่มต้น — fusion ในตัว นิ่งสุด
IMU_BNO055_MAGBNO055 + เข็มทิศใช้ magnetometer ช่วยยึดทิศ (absolute)
IMU_BNO055_ZUPTBNO055 ZUPTอ่าน gyro ดิบข้าม fusion + หยุดนิ่งรีเซ็ต drift (ZUPT)
IMU_MPU6050MPU6050ราคาประหยัด gyro 6 แกน
IMU_GY91GY-91 (MPU9250)9 แกน รวม magnetometer
IMU_BNO085BNO085fusion รุ่นใหม่ ตอบสนองไว
IMU_BNO085_MAGBNO085 + เข็มทิศBNO085 พร้อม magnetometer
IMU_ICM20948ICM-209489 แกน — เล่น gyro ล้วน (ต้องจูน scale ดู icm_scaleCalibrate())
💡 หมายเหตุ: ค่า type เป็นค่าคงที่ (constant) พิมพ์ตามตารางได้เลย ไม่ต้องใส่เครื่องหมายคำพูด
ตัวอย่าง — ใช้ ICM-20948
void setup() {
  razors4();
  setIMU(IMU_ICM20948);  // เลือกก่อน initIMU เสมอ
  initIMU();
  calibrateYawStart();
}
voidicm_scaleCalibrate(turns)
จูน scale-factor ของ gyro — เฉพาะ ICM-20948 (จูนครั้งเดียว เก็บถาวรใน EEPROM)
ICM-20948calibrateEEPROM
▶
พารามิเตอร์ชนิดค่าเริ่มต้นคำอธิบาย
turnsint5จำนวนรอบที่จะหมุนหุ่นด้วยมือ (มากรอบ = แม่นกว่า)

เทียบมุมที่ gyro วัดได้กับมุมหมุนจริง แล้วเก็บค่าตัวคูณแก้ไว้ — ทำให้ ICM-20948 อ่านมุมตรง ขั้นตอนใช้งาน:

  1. บอร์ดบี๊บ 1 ครั้ง → เริ่มจับมุม
  2. หมุนหุ่นด้วยมือ N รอบเต็ม กลับมาจุดเดิม (ตรงเป๊ะ)
  3. กดปุ่ม Go (SW10 / pin10)
  4. บี๊บ 2 ครั้ง = คำนวณเสร็จ เก็บลง EEPROM แล้ว
⚠ วางชั่วคราว: จูนครั้งเดียวพอ (ค่าอยู่ถาวร) — จูนเสร็จให้เอาบล็อก/บรรทัดนี้ออก ไม่งั้นจะรอกดปุ่มทุกครั้งที่เปิดเครื่อง
ตัวอย่าง — จูน 5 รอบ
void setup() {
  razors4();
  setIMU(IMU_ICM20948);
  initIMU();
  icm_scaleCalibrate(5);  // จูนเสร็จแล้วลบบรรทัดนี้ทิ้ง
  calibrateYawStart();
}
