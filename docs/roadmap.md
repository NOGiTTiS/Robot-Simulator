### 2. 🧊 Interactive Obstacle Placement (ระบบวางสิ่งกีดขวางแบบ Interactive)
- **วัตถุประสงค์**: เพิ่มความสมจริงในการทดสอบเซนเซอร์วัดระยะทาง (Distance / TOF Sensor)
- **รายละเอียด**:
  - เพิ่มเครื่องมือคลิกลากวางสิ่งกีดขวาง (เช่น กล่องไม้, สิ่งกีดขวางรูปทรงกระบอก, กำแพง) ลงบน 2D Canvas / 3D WebGL Viewport ได้โดยตรง
  - รองรับการย้ายตำแหน่ง (Drag & Drop), หมุน (Rotate), และลบสิ่งกีดขวาง
  - เซนเซอร์ TOF คำนวณระยะห่างสะท้อนจากสิ่งกีดขวางแบบ Real-time

### 3. ⌨️ Keyboard Shortcuts Control System (ระบบคีย์ลัดสั่งงาน)
- **วัตถุประสงค์**: เพื่อความสะดวกในการควบคุมการจำลองโดยไม่ต้องละมือจากคีย์บอร์ด
- **รายละเอียด**:
  - `Ctrl + Enter` (หรือ `Cmd + Enter` บน macOS): สั่ง ▶ Run / ⏸ Pause การจำลอง
  - `Ctrl + R` (หรือ `Cmd + R` บน macOS): Reset หุ่นยนต์กลับจุดเริ่มต้น
  - `Ctrl + S`: Export โปรเจกต์เป็นไฟล์ `.ino` / `.cpp` ลงเครื่อง
  - `Esc`: ปิดหน้าต่าง Modal ที่เปิดอยู่ทั้งหมด

---

### 4. 🔇 Audio Mute / Unmute Toggle (สวิตช์เปิด/ปิดเสียง Buzzer)
- **วัตถุประสงค์**: ป้องกันเสียงรบกวนเมื่อใช้งานพร้อมกันหลายเครื่องในห้องเรียน
- **รายละเอียด**:
  - เพิ่มปุ่มไอคอนสปีเกอร์ (🔊 Mute / Unmute) บน HeaderBar
  - สามารถปิดเสียง Buzzer สังเคราะห์จากคำสั่ง `beep()`, `sound()`, `tone()` ได้โดยไม่ต้องแก้โค้ด
  - บันทึกสถานะการเปิด/ปิดเสียงลง LocalStorage
